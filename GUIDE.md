# Testing with GNOME Boxes

To test **BergOS Retro v1.0** using GNOME Boxes (Macchine / Boxes):

1. Launch **Boxes** and click **+** (Create / New Virtual Machine).

---

2. Select **Express Installation** or **Select File** and choose `bergos-retro-v1.0-i386.iso`.

---

3. Configure the virtual machine resources:
   - **Name:** `bergos-retro-v1`
   - **Memory:** `1.0 GiB` (runs smoothly even with `512 MiB`)
   - **Storage Limit:** `10.0 GiB`

<img width="555" height="506" alt="Schermata_20261022_153402" src="https://github.com/user-attachments/assets/29f36368-748c-4528-9ba9-cbdc81af91b1" />

---

4. Click **Create** to launch the Live session.

Once booted, select **Boot BergOS Retro (Live Session)** from the menu to enter the IceWM desktop automatically.

<img width="1255" height="789" alt="Schermata_20261022_153445" src="https://github.com/user-attachments/assets/66211874-468c-4e8b-beb4-33466d64305e" />

---

5. Wait a couple of seconds and the desktop environment should boot right up

<img width="1253" height="948" alt="Schermata_20261022_153504" src="https://github.com/user-attachments/assets/3e1d13d1-0242-40d8-9eaf-e27ec248b4fd" />

---

6. To install BergOS Retro, click on the Start Menu, select the "System" folder and choose the "Install Debian" option

<img width="1253" height="942" alt="Schermata_20261022_153527" src="https://github.com/user-attachments/assets/71922b33-384d-4309-a157-1d2c5e7133fe" />

---

7. Last but not least, enjoy!
